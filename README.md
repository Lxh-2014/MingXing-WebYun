# Web-明星云网盘需求文档

## 1. 网站概述

### 1.1 网站名称
明星云网盘

### 1.2 网站描述
面向老师/学生群体的云网盘，内含上传和下载功能等基础功能

### 1.3 目标用户
老师/学生群体

## 2. 功能需求

### 2.1 用户登录功能
- 登录页面作为网站入口，登录后方可使用其他页面
- 账号信息存储在./user.json文件中
- 密码哈希值存储在./password.json文件中

### 2.2 首页功能
- 顶部显示：
    - 头像（可自定义颜色），旁边加上名称。
- 侧边栏：
    - 文件
    - 设置

### 2.3 设置功能
- 用户信息展示
    - 头像显示（用户名首字母或自定义图片）
    - 修改头像功能：
        - 支持上传自定义图片作为头像（支持所有图片格式）
        - 支持选择预设颜色作为头像背景（12种颜色可选）
- 头像数据存储在浏览器本地（localStorage）

### 2.4 文件功能
- 右键打开菜单
    - 下载
    - 删除
    - 重命名
    - 详细信息
- 顶部可上传文件/新建文件夹
    - 上传文件（全部格式均支持，任意字符（除开：\/:*?"<>|）名称）
    - 新建文件夹（名称默认：新建文件夹，名称除开：\/:*?"<>|和 Windows 的保留名称）
- 存储
    - ./files 文件夹
- 隔离
    - 所有用户均可访问全部内容
## 3. 设计风格

### 3.1 配色方案
主色调采用清新的蓝色系（#4A90E2），辅以白色背景和浅灰色边框，营造专注办公的氛围

### 3.2 视觉细节
采用圆角卡片式设计，按钮具有轻微阴影效果，图标采用线性风格，页面切换使用平滑过渡动画

### 3.3 整体布局
采用居中卡片式布局，文件区域突出显示，操作按钮位置固定，确保体验的连贯性和专注度
